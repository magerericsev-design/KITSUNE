# KITSUNE — Le Moulin et le Gomoku

Deux jeux de réflexion gratuits par Eric Mager, créés avec l’aide de Codex et de l’IA. Jeu indépendant, sans affiliation avec Netflix ou The Devil’s Plan. L’interface de jeu est en français.

[Découvrir les jeux et leurs règles sur le LAB](https://eric-mager-lab.terrelfe.chatgpt.site/fr/projets/kitsune/)

## Jouer en ligne

[**Jouer à KITSUNE 2.0 dans le navigateur**](https://magerericsev-design.github.io/KITSUNE/v2/index.html) — gratuit, sans compte. Le salon réseau du Moulin reste réservé aux applications Windows et Android. Sur téléphone, jouer en paysage. Safari et l’installation PWA sur iPhone/iPad restent à vérifier sur appareil réel.

## Installer et jouer

- **Windows 64 bits · 2.0** : [télécharger l’installateur](https://github.com/magerericsev-design/KITSUNE/releases/download/v2.0.0/KITSUNE-Windows-2.0.0-Installation.exe). Installateur non signé : Windows peut afficher un avertissement.
- **Android 7 ou plus · 2.0** : [télécharger l’APK](https://github.com/magerericsev-design/KITSUNE/releases/download/v2.0.0/KITSUNE-Android-2.0.0.apk). Autoriser l’installation hors Google Play si nécessaire. L’APK utilise la même clé de test et le même identifiant que la version précédente. La mise à jour et la reprise ont été vérifiées sur émulateur ; la V2 reste à tester sur téléphone physique.

Le Moulin propose l’IA locale, le jeu local à deux et un salon en connexion directe. Le Gomoku propose deux niveaux d’IA, le jeu local classique et une variante aveugle contre l’IA. Les sauvegardes des deux jeux sont séparées.

[Release 2.0 et sommes SHA-256](https://github.com/magerericsev-design/KITSUNE/releases/tag/v2.0.0). Les sources historiques n’ont pas été retrouvées : les projets ont été récupérés à partir des distributions existantes. Le workflow Pages vérifie l’empreinte du build Web avant déploiement.
