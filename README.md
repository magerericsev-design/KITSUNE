# KITSUNE — Le jeu du moulin

Jeu de stratégie gratuit par Eric Mager, créé avec l’aide de Codex et de l’IA. Jeu indépendant, sans affiliation avec Netflix ou The Devil’s Plan. Interface de jeu en français.

[Découvrir le jeu, son histoire et ses règles sur le LAB](https://eric-mager-lab.terrelfe.chatgpt.site/fr/projets/kitsune/)

## Jouer en ligne

[**Jouer à KITSUNE dans le navigateur**](https://magerericsev-design.github.io/KITSUNE/) — édition Web expérimentale, gratuite, sans compte. Solo et deux joueurs sur le même appareil ; le salon réseau direct est réservé aux applications Windows et Android. Jouer en paysage sur téléphone. Après une première visite complète, le jeu peut fonctionner hors ligne sur un navigateur compatible. Safari et l’installation PWA sur iPhone/iPad ne sont pas encore vérifiés sur matériel Apple.

## Installer et jouer

- **Windows 64 bits · 1.1** : [télécharger l’installateur](https://github.com/magerericsev-design/KITSUNE/releases/download/v1.2.0/KITSUNE-Windows-1.1-Installation.exe). Installateur non signé : Windows peut afficher un avertissement.
- **Android 7 ou plus · 1.2.0** : [télécharger l’APK](https://github.com/magerericsev-design/KITSUNE/releases/download/v1.2.0/Kitsune-1.2.0.apk). Autoriser l’installation hors Google Play si nécessaire. APK signé avec une clé de test. Le créateur indique que son premier essai sur Redmi 15 5G fonctionne bien ; la saisie avec le clavier tactile reste à vérifier.

[Release, sources récupérées et sommes SHA-256](https://github.com/magerericsev-design/KITSUNE/releases/tag/v1.2.0). Le [projet Web récupéré à partir de l’APK](https://github.com/magerericsev-design/KITSUNE/releases/download/v1.2.0/KITSUNE-Web-sources-recuperees-v2.zip) est disponible en archive : les sources d’origine et leur historique n’ont pas été retrouvés. Le workflow Pages publie le build Web vérifié et contrôle son empreinte.
